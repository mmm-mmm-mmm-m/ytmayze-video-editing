# Pacing examples

- Four bars of playback can be useful listening even without speech. Identify the musical development before shortening.
- Several paste actions repeat the same information. An authorized structural edit can retain the first paste and the next new musical step.
- A spoken gag competes with the creator. Give it an intelligible slot when timing can change; with locked cuts, use a shorter fitting device or propose an alternative.
- Trimming a punchline can remove its recognizable payoff. Judge the revised hold with the lead-in and return rather than assigning every gag one duration.
- A sound-led visual transition can bridge sections without adding an unrelated black gap.
