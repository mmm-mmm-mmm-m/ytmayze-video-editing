# Optional project style note

Use a brief note when it will prevent redoing a substantial project audit. Keep it with the editable working project, not in a global skill as stale project state.

- Current working version and source; date and where edits may be unsaved.
- Authorized pass, locked timing/audio/sections, and current format/fps.
- A few accepted reference moments or reusable editable presets, with why they work.
- Active cue decisions and source/event anchors; pending visual/listening/user review.
- Recent user corrections with context; superseded treatments identified as such.

Update only the useful state as the project develops. Do not promote tentative scene choices into global rules. Re-check paths, versions and active app state at the next session.
