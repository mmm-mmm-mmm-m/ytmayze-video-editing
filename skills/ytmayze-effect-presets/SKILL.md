# @ytmayze Effect Presets

Turn a useful treatment into something another edit can reuse without reconstructing its mechanics. Preserve editable controls and transfer evidence. The current creative task decides whether it belongs; a preset is an option. Use `ytmayze-reactive-vfx` when available for event choice and musical timing.

## Find or capture the reusable part

This public kit contains methods and a read-only EffectCraft inspector. It includes no native presets, captured project templates or media. Start with the creator's own library and the [library guide](references/catalog.md). Inspect the user-designated current source before extracting anything. Separate reusable mechanics from old styling. If the source or dependencies are unavailable, provide a labeled recipe or extraction plan.

Save the smallest useful editable unit: one motion gesture, a clearly timing-specific phrase, a format-specific camera layout or a composite with replaceable screen, highlights, text and sound. A rendered insert is a playback asset, not an editable preset. Preserve the original and name meaningful variants separately.

## Package and document

Use the editor's supported export/import or native template mechanism. Preserve effect order, interpolation and required dependencies. Avoid baking footage, absolute placements, layer IDs or one song's event map into a general gesture. A phrase can retain its internal rhythm when labeled as such.

Use a [compact preset card](references/card-format.md) for the artifact, intended use, dependencies, replacement slots, geometry/timebase, impact offset and validation evidence. Keep private source paths and personal metadata out of shared cards. Include media or fonts only when their redistribution permission is established.

For EffectCraft, read [native transfer](references/native-transfer.md). The [read-only inspector](scripts/inspect_native_preset.py) reports effect order, expression presence and key-time extents without executing expressions. Supply the file's actual timebase and frame rate when converting times; a last key is not a display duration. It is an inventory helper, not a native compatibility validator.

## Adapt to the destination

Inspect composition, existing effects, crop and layer relationships. Transfer the motion shape, then map new events and align the perceived impact. Adapt attack, hold and release to the sound. Distinguish preserving elapsed seconds from preserving a rhythmic subdivision; quantize once and inspect coincident keys.

Use an isolated adjustment/template instance where useful. Reconcile existing framing and effects instead of replacing or compounding them accidentally. Keep brightness, color and glow independently adjustable from motion. For a laptop-style shortcut explanation, use the [composite guide](references/laptop-showcase.md) and replace screen, key events, explanatory copy and sound together.

## Verify and hand off

Edit a host only when the task authorizes it, in a named editable copy. Check representative entry, peak and release; source cuts; edge coverage; readable action/text; sound tails; and the return to speech. Verify media loading and protected timing/audio.

Return the editable artifact, concise application instructions and the exact verification scope. Structure, native import/reopen, continuous viewing/listening and owner acceptance are separate evidence. Save useful variants and narrow lessons without turning local choices into global rules.
