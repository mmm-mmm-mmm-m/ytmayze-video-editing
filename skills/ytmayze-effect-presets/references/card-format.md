# Compact preset card

Use only fields that help another editor reuse this asset. A short Markdown card is sufficient; machine-readable metadata is useful when inventorying a library.

- **Identity:** name, variant/revision, artifact type and path; hash when copying/exporting an exact source.
- **Intent:** what it does, useful contexts, a counterexample. Keep personal/scene choices conditional.
- **Origin:** source revision or capture, and what was actually inspected. Label a reconstruction or approximation.
- **Mechanics:** editor/version/format, actual effect/plugin dependencies and order; target layer or composite slots; append/replace behavior; changed vs protected properties.
- **Adaptation:** native units/timebase, source fps/geometry, relative peak/duration, margins and neutral/baseline behavior; controls that can be reduced independently. Retain a phrase's intentional rhythm only when labeled.
- **Evidence:** artifact created/copied; structural inspection; native import/reopen and environment; viewed/listened scope; owner acceptance and its limits. Unknown stays unknown. Historical evidence keeps its date/environment rather than being promoted to current validation.

Report only changed evidence when revising a card. Do not require a full metadata ceremony to save a simple layout, or claim every newly saved version was watched/listened to.
