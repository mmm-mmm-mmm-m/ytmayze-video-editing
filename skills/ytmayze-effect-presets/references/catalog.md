# Building a useful preset library

Look for a treatment the creator actually wants to reuse. This package does not include a ready-made asset library.

| Treatment | Useful reusable unit | Transfer check |
| --- | --- | --- |
| Short impact | Editable attack/recovery, separate motion and flash controls | Align perceived peak; inspect return to untreated picture |
| Sustained bass motion | Attack, hold and release shaped around the sound | Replace old event timings and adapt the envelope |
| Directional slide | Controlled retreat/warp with suitable edge coverage | Match direction/duration and retain readable notes |
| Camera layout | Format-specific camera and DAW regions | Adapt to source geometry and active controls |
| Shortcut showcase | Device/screen, key highlights, explanation and sound | Verify current shortcut, action and synchronized cues |

Name assets by behavior and format. Label complete song phrases as timing-specific. Record dependencies and validation limits in a compact card before sharing.
