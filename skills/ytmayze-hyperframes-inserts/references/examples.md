# Insert integration examples

- Borrow a reference’s composition or timing device, then adapt it to the creator’s actual words, performance and audience. A successful render alone does not establish fit.
- Real UI capture and generated surroundings have different roles. Missing selection, audition or drag footage stays a missing capture requirement.
- A click timestamp is an event, not a readable shot. Allocate real lead-in and result context, compressing loading separately from the audible audition.
- A picture hold needs an explicit audio map. Letting unedited source sound run ahead of a held picture breaks sync.
- If the user requests a storyboard, deliver that artifact at the requested stage. An existing request to render or integrate need not gain an extra approval stop.

HyperFrames implementation tools are optional external dependencies, installed separately. This kit supplies creative integration guidance rather than the rendering runtime.
