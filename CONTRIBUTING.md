# Contributing

Thanks for helping improve ytmayze video editing. This is an experimental, early release; practical reports are more useful than broad claims.

## Useful feedback

Please include:

- Which skill and agent you used, and the editor or media tools available.
- The task, time range, and direction you gave the agent.
- What happened, what you expected, and the specific change that would help.
- Whether the result was inspected in the native editor and reviewed by a person.

Remove private project details, account data, and identifying media before sharing logs or screenshots. Do not submit source footage, project files, third-party images, fonts, or audio unless you have the right to share them and have checked with the owner first.

## Changes to skills

Keep guidance reusable across projects. Put a general lesson in the skill that owns that part of the workflow; keep client-specific timecodes, assets, and experiments in the project where they belong. Prefer concrete instructions over promises about quality or speed. Preserve the user's rough cut and protected material unless they explicitly direct otherwise.

When proposing an example, label whether it is a source-style reference or a result made with a specific public release. A release-produced example should identify the release, agent, editor, and review status, and should be used only with appropriate rights and permission.

## Changes to this repository

Open a pull request with a short summary, affected skills, and any checks you actually ran. Do not describe an unrun check as passing. Do not include private paths, chat identifiers, private quotations, raw project media, credentials, or machine-specific metadata. See the [release protocol](docs/RELEASE-PROTOCOL.md) for maintainer staging and release steps.
