# Licence decision

This is a public experimental preview. The owner has deferred choosing a licence, so the repository does not claim to be an open-source release under MIT or another standard licence.

MIT is the recommended option for the skill instructions and helper code: it allows reuse and modification while retaining the copyright and licence notice. Before adopting it, the owner should confirm the copyright attribution and add the actual licence text. See the [MIT licence summary and text](https://choosealicense.com/licenses/mit/).

Screenshots, source videos, music, fonts, product UI, trademarks and any future media assets are separate from that proposed code licence. Their presence in an example does not grant a licence to the underlying third-party material. Raw media and templates are excluded from this package.

The owner should resolve this decision before advertising an openly licensed release. Publishing this preview does not select a licence on their behalf.
